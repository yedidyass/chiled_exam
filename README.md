# מבחנים בבית

אפליקציית PWA בעברית למעקב אחרי המבחנים של הילדים.

- **צד לקוח:** React + Vite + vite-plugin-pwa (`src/`)
- **שרת:** Cloudflare Worker עם Hono (`worker/`), שמגיש גם את קבצי האפליקציה
- **מסד נתונים:** Cloudflare D1 (`migrations/`)

## שיתוף בין ההורים
כל משפחה מקבלת קוד סודי. במסך **הגדרות → שיתוף** שולחים קישור הצטרפות, ומי שפותח אותו רואה ועורך את אותם נתונים.

## תמונות ילדים
מעלים תמונה במסך **ילדים ← עריכה**. הדפדפן חותך אותה לריבוע, מקטין ל-320px ומקודד ל-JPEG (כ-20KB) לפני ההעלאה. התמונות נשמרות ב-D1 (טבלה `child_photos`), מוגשות רק עם קוד המשפחה, ונשמרות גם במטמון המקומי כדי שיוצגו בלי אינטרנט. השרת בודק את סוג הקובץ לפי התוכן שלו (JPEG/PNG/WebP), עד 300KB.

## התראות push
- **תזכורת ערב** (א׳–ה׳, 16:00 UTC = 18:00/19:00 בישראל): מבחנים של מחר ומחרתיים. ביום חמישי התזכורת מכסה עד יום שני, כי בשישי ובשבת לא נשלחות התראות.
- **סיכום שבועי** (ראשון, 05:30 UTC): כל מבחני השבוע.
- מפעילים בכל מכשיר בנפרד: **הגדרות → התראות לפני מבחנים**. באייפון צריך קודם להתקין את האפליקציה למסך הבית.
- מפתחות VAPID נוצרים אוטומטית בפעם הראשונה ונשמרים ב-D1, אין צורך בהגדרה.
- המימוש (`worker/push.ts`) הוא Web Push תקני (RFC 8291/8292) על WebCrypto, בלי תלויות.

## פיתוח מקומי
```bash
npm install
npm run build
npm run dev:api   # Worker + D1 מקומי על פורט 8787
npm run dev       # Vite על פורט 5173 (מעביר את /api ל-8787)
```

## Deploy
ה-workflow `.github/workflows/deploy.yml` רץ בכל push ל-`main` (או ידנית מ-Actions):
1. בונה את האפליקציה
2. יוצר את מסד ה-D1 `chiled-exam-db` אם הוא לא קיים
3. מריץ מיגרציות
4. מעלה את ה-Worker

Secrets נדרשים ב-GitHub Actions:
- `CF_API`: טוקן API של Cloudflare עם ההרשאות *Workers Scripts: Edit* ו-*D1: Edit* (ו-*Account Settings: Read*)
- `CF_ACCOUNT_ID` (אופציונלי): רק אם לטוקן יש גישה ליותר מחשבון אחד
